# Lab 3: 

## Тема
Спадкування, поліморфізм, використання конструкторів із `base(...)`, перевизначення методів.

## Мета роботи
Навчитися створювати базові та похідні класи, використовувати спадкування, демонструвати поліморфізм у колекціях.

## Виконання
- Створено базовий клас `Product` з полем `Price`.
- Реалізовано похідні класи:
  - `Book` (з додатковим полем `Author`);
  - `Food` (з полем `ExpirationDate`).
- Використано `base(...)` у конструкторах.
- Перевизначено метод `DisplayInfo()` з використанням `override`.
- Продемонстровано роботу поліморфізму на колекції `List<Product>`.
